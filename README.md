# Digital Sleep Lab

Digital Sleep Lab integrates physiological indicator monitoring, AI-powered insight, and personalized health guidance to create a comprehensive digital sleep lab experience.

Digital Sleep Lab 将生理指标监控、AI 深度洞察与健康建议融为一体，为用户提供全方位的数字化睡眠实验室体验。

---

## Dual-Node Strategy

Digital Sleep Lab adopts a "Strategic Physical Isolation" model to balance community transparency with protection for core intellectual property.

### 1. Digital-Sleep-Lab-frontend (Public Node)
- Status: Public, MIT licensed
- Scope: UI/UX, data visualization, client-side routing, and AI advice orchestration
- Goal: Provide a professional, high-performance interface for laboratory subjects

### 2. Digital-Sleep-Lab-core (Sovereign Node)
- Status: Private, proprietary
- Scope: Neural synthesis algorithms, proprietary prompt engineering, model weights, and sensitive data processing logic
- Goal: Act as the protected engine of Digital Sleep Lab

### 3. Digital-Sleep-Lab-docs (Public Node)
- Status: Public
- Scope: Architecture diagrams, whitepapers, and protocol documentation
- Goal: Present system capabilities clearly to collaborators and the public

---

## Security And Asset Management

- Zero-Key Policy: No API keys or database credentials are committed to the public node
- Strict Git Ignore: Sensitive environment files and model artifacts stay out of the public stream
- API Boundary: The frontend interacts with the core through secure, authenticated relays
